Movie Search App

A React-based movie search application built with Vite, Axios, and the OMDb API.

Features

- Search for movies using the OMDb API
- Display movie posters, titles, and release years
- Save favorite movies
- Prevent duplicate favorites
- Persist favorites using localStorage
- Loading state management
- Error handling
- Handling for empty search results

Installation

npm install

Run the Application

npm run dev

Technologies Used

- React
- Vite
- Axios
- OMDb API
- localStorage
